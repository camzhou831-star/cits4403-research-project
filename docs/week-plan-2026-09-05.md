## 2. 关于"决策未冻结能否开始写代码"

`README.md` 的 gate 要求代码前冻结 D001-D008。但逐条检查后，**最小 baseline SIR 不依赖其中任何一项的结构性选择**：

| 决策 | 对 baseline 代码的影响 |
|---|---|
| D001 delay origin | 只影响 intervention 触发，baseline 无干预；实现时把"activation day"作为可替换接口 |
| D002 capacity、D003 `k`、D004 `D`、D006 `max_days` | 纯配置数值，写入 config 默认值并标注 `provisional` |
| D005 `p_in/p_out` | 只影响 network generator（本周 should-have，可延后） |
| D007 baseline reporting、D008 headline metric | 只影响分析/报告 |

因此：**baseline SIR 可以在 facilitator 反馈前开始，前提是 config 中所有 provisional 值都有标注，且不实现 movement/intervention。** 这一判断需要两名成员在 decision log 中确认。
